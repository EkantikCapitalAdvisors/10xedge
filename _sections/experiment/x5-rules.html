HOW SIZE STEPS UP

Position size steps up by one contract for every {{rule.per}} of account equity, and steps back down the same way. The account trades one contract until equity reaches {{rule.second}}. Because size follows equity, the target is a multiple, not a dollar figure: the same rules run at any account size from the minimum.
